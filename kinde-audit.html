Kinde Audit

A read-only report of users in a Kinde business. It flags suspended users, users who never signed in, users inactive for a set number of days, users with many failed sign-ins, and users with no organisation. Makes no changes in Kinde.

  • Configurable inactivity threshold
  • Safe: read-only, no mutations
