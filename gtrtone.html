Case Study · Audio / Rust

GTRTONE ASP

A native macOS Audio Unit that plays Neural Amp Modeler (.nam) captures, drives them at the level they were trained on, and runs an automated sound processor over the result. It also builds tones that are not any single capture.

← Back to work

What it does

  • Hosts NAM captures and runs them at their trained input level
  • Automated Sound Processor (ASP) shapes the result in real time
  • Tone Forge builds new tones beyond any single capture
  • Ships as Audio Unit, CLAP, VST3, and standalone

Architecture

crates/asp-dsp — host-independent engine (NAM host, ASP, Tone Forge, DSP). crates/gtone-ai — Ollama client + tone-plan schema (no audio, no host). crates/gtone-plugin — Audio Unit / CLAP / VST3 / standalone shell via truce.
